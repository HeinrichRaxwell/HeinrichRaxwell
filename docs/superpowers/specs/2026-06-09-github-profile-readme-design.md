- Do not display the user's real name.
- Use `HeinrichRaxwell` as the public identity.

- Use Instagram as the only public contact: `https://instagram.com/visivora`.

## Content Direction

The selected direction is `Professional Interactive`.

The README should use tasteful animated/readme-native elements without becoming visually noisy:

- animated header generated by `capsule-render`
- typing SVG for current learning and build focus
- profile badges for views, followers, and campus
- grouped technology badges
- GitHub stats and activity graph placed after the main content
- collapsible sections only where they add useful structure

GitHub README limitations are accepted: no custom JavaScript, no arbitrary browser interactivity. Interactivity means SVG animations, live cards, badges, stats, and native `<details>` disclosure blocks.

## Voice And Language

Use English as the primary language with short Indonesian touches.

Tone:

- concise
- professional
- humble
- practical
- not overclaiming expertise

Avoid:

- fake seniority
- excessive emojis
- cluttered badge walls
- claims that imply production trading or financial advice
